Английский спрингер-спаниель

Самая старая охотничья порода Англии. Характер: Решительный, активный, преданный. Для кого: Идеален для активных семей и спорта (аджилити).

Русский охотничий спаниель

Единственная отечественная порода. Характер: Настойчивый, выносливый, ласковый дома. Для кого: Лучший друг для охотников и туристов.

Кавалер-кинг-чарльз-спаниель

Королевская порода. Характер: Безгранично добрый, не переносит одиночества. Для кого: Идеален для квартир и семей с маленькими детьми.

Английский кокер-спаниель

Классика жанра. Характер: Веселый, постоянно виляет хвостом. Очень общителен. Особенность: Требует тщательного ухода за шерстью.

Американский кокер-спаниель

Шоу-звезда. Характер: Послушный, ласковый, чувствительный. Для кого: Для тех, кто готов уделять много времени грумингу.

Континентальный той-спаниель (Папильон)

Собака-бабочка. Характер: Входит в топ самых умных собак. Очень энергичный и смелый. Особенность: Легко учит любые трюки.

Ирландский водяной спаниель

Самый крупный. Характер: Шутливый, энергичный, превосходный пловец. Особенность: Имеет "крысиный" голый хвост и водонепроницаемую шерсть.

Кламбер-спаниель

Медлительный аристократ. Характер: Спокойный, серьезный, настойчивый. Для кого: Идеален для неспешных прогулок.

Коикерхондье

Голландская редкость. Характер: Осторожный, умный, чуткий. Особенность: Черные кончики ушей ("серьги") — визитная карточка.

Бретонский эпаньоль

Энергия Франции. Характер: Неутомимый охотник, очень сообразительный. Для кого: Нуждается в серьезных физических нагрузках.

Вельш-спрингер-спаниель

Ярко-рыжий красавец. Характер: Преданный, выносливый, любит воду. Особенность: Всегда только бело-рыжий окрас.

Филд-спаниель

Редкая порода. Характер: Уравновешенный, послушный, ласковый. Для кого: Прекрасный компаньон для жизни за городом.

Суссекс-спаниель

Низкорослый и золотистый. Характер: Спокойный, иногда упрямый, очень привязчивый. Особенность: Уникальный "шоколадно-золотой" цвет шерсти.

Кинг-чарльз-спаниель (Английский той)

Крошечный компаньон. Характер: Тихий, нежный, домосед. Особенность: Отличается от Кавалера более короткой мордочкой.

Тибетский спаниель

Маленький лев монастырей. Характер: Бдительный, независимый, преданный семье. Особенность: Повадками часто напоминает кошку.

Большой мюнстерлендер

Немецкий талант. Характер: Послушный, контактный, универсальный охотник. Для кого: Для тех, кто ценит дисциплину и работу в поле.

Малый мюнстерлендер

Малый, но мощный. Характер: Темпераментный, преданный, очень понятливый в дрессировке. Особенность: Пользуется огромной популярностью в Европе.

Французский спаниель

Аристократ из Франции. Характер: Очень нежный, спокойный, умный. Особенность: Обладает врожденной деликатностью в общении.

Голубой пикардийский спаниель

Редкий окрас. Характер: Выносливый, послушный, ладит с детьми. Особенность: Шерсть имеет характерный серо-черный отлив.

Немецкий вахтельхунд

Профи охоты. Характер: Страстный в поиске, дома — добрый друг. Для кого: Только для активных владельцев или профессиональных охотников.

Американский водяной спаниель

Универсальный помощник. Характер: Дружелюбный, смелый, обожает плавать. Особенность: Шерсть состоит из плотных мелких завитков.

Веттерхун (Голландский водяной)

Суровый защитник. Характер: Независимый, бдительный, верный. Особенность: Отличный охранник, в отличие от большинства других спаниелей.

Бойкин-спаниель

Южное очарование (США). Характер: Контактный, игривый, легко дрессируется. Особенность: Популярный участник соревнований на воде.

Понт-одемерский спаниель

Редчайший вид. Характер: Веселый, очень ласковый, любит играть. Особенность: Имеет забавный "хохолок" из кудряшек на голове.

Сент-юсужский спаниель

Французский компаньон. Характер: Легкий в общении, послушный, преданный. Для кого: Отличная семейная собака для длительных прогулок.

Стабихун

Гордость Нидерландов. Характер: Спокойный, бдительный, невероятно терпеливый. Особенность: Считается одной из самых редких пород в мире.

Дрентская куропаточная собака

Мастер стойки. Характер: Мягкий, преданный, очень любит детей. Особенность: На охоте работает в тесном контакте с хозяином, не уходя далеко.
